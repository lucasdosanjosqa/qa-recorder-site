Política de Privacidade — QA Recorder

Última atualização: 02/05/2026

QA Recorder é uma extensão local-first criada para ajudar profissionais de QA a registrar sessões de teste, capturar evidências, organizar validações e gerar relatórios prontos para ferramentas como Jira.

1. Funcionamento local

QA Recorder não exige login, não usa cloud e não envia dados para servidores externos próprios. As informações criadas ou capturadas pelo usuário permanecem localmente no navegador e/ou nos arquivos exportados manualmente pelo próprio usuário.

2. Dados processados pela extensão

Durante o uso, a extensão pode processar localmente informações necessárias para executar suas funcionalidades, incluindo:

  • sessões de teste;
  • cenários e validações;
  • descrições, notas e status;
  • screenshots e evidências visuais;
  • seletores de elementos da página;
  • informações técnicas de rede, como método, URL, status e tempo de requisição;
  • templates locais;
  • preferências da extensão.

Essas informações são usadas exclusivamente para permitir que o usuário documente execuções de teste e gere relatórios.

3. Conteúdo capturado pelo usuário

O usuário controla quais páginas, evidências e informações serão capturadas. Caso o usuário capture telas ou informações que contenham dados pessoais, credenciais, dados financeiros, dados sensíveis ou comunicações, esse conteúdo permanecerá localmente no navegador ou nos arquivos exportados pelo próprio usuário.

4. Compartilhamento de dados

QA Recorder não vende, não transfere e não compartilha dados do usuário com terceiros. A extensão não utiliza os dados para publicidade, rastreamento, análise comportamental, crédito, empréstimo ou qualquer finalidade não relacionada ao registro de testes.

5. Armazenamento

Os dados são armazenados localmente no navegador do usuário por meio dos mecanismos de armazenamento disponíveis para extensões do Chrome. O usuário pode limpar, excluir ou exportar seus dados conforme as funcionalidades disponíveis na extensão.

6. Código remoto

QA Recorder não executa código remoto. Todo o código necessário ao funcionamento da extensão está incluído no pacote publicado na Chrome Web Store.

7. Segurança

A extensão foi projetada para funcionar localmente e reduzir a exposição de dados. Ainda assim, o usuário deve evitar capturar ou exportar informações sensíveis quando não forem necessárias para a documentação do teste.
